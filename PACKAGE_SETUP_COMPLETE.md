## Installation
1. Open IntelliJ IDEA / CLion / AppCode
2. Go to Settings → Plugins → ⚙️ → Install Plugin from Disk...
3. Select: `build/distributions/metal-shader-support-plugin-1.0.7.zip`
4. Restart IDE (if prompted)
5. Go to Tools → Metal Shader Support → License → Activate License...
6. Enter license key: `METAL-ENT-2025-JAKUB-ENTERPRISE`
