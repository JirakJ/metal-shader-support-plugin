## 📖 Full Description

### 🎨 Write Metal Shaders Like a Pro — Right Inside Your IDE

**The Problem:** Metal shader development in JetBrains IDEs means working with plain text files — no syntax highlighting, no completion, no error detection. Developers constantly context-switch between Xcode and their preferred IDE.

**The Solution:** Metal Shader Support brings full language intelligence for Apple's Metal Shading Language directly into IntelliJ-based IDEs. From syntax highlighting to live shader preview and GPU profiling, everything you need is one plugin away.

---

### ✨ Key Features

### 🎯 Perfect For

- **iOS/macOS developers** writing Metal shaders in JetBrains IDEs
- **Graphics programmers** who prefer IntelliJ over Xcode for shader work
- **Game developers** targeting Apple platforms with Metal rendering
- **Cross-platform teams** needing shader transpilation between Metal, SPIR-V, and HLSL

1. **Install** the plugin from JetBrains Marketplace
2. **Open** or create a `.metal` file — syntax highlighting activates automatically
3. **Start typing** to see Metal-aware code completion suggestions
4. **Use live templates** — type common abbreviations and expand with Tab
5. Open the **live shader preview** and **GPU profiler**
