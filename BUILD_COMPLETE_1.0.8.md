## 📦 Installation Instructions

### For End Users
```bash
1. Open IntelliJ IDEA (2024.2 or newer)
2. Settings → Plugins → ⚙️ → Install Plugin from Disk...
3. Select: build/distributions/metal-shader-support-plugin-1.0.8.zip
4. Restart IDE
5. Done! Open any .metal file to see it work
```

### For Development
```bash
# Build plugin
./gradlew clean buildPlugin

# Run in IDE sandbox
./gradlew runIde

# Run tests
./gradlew test
```
